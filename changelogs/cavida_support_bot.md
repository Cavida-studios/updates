# Cavida Studios — changelog

## 2.0.1 — 2026-11-13

- Giftcardcodes worden als zelfstandig bericht in het ticketkanaal geplaatst, met een melding aan de ticketmaker.
- Het privébeheerpaneel en de eventuele DM blijven beschikbaar; mislukte kanaalbezorging wordt afzonderlijk gemeld zodat dezelfde code opnieuw kan worden verstuurd.
- De bot gebruikt Cavida-branding en controleert zijn versie via het centrale openbare Cavida-versieregister, bij starten en iedere zes uur.
- Updateberichten verwijzen naar Purchased Assets in het Cfx.re-portaal. Technische GitHub-adressen worden uit consolemeldingen gefilterd.
